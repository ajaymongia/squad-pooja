Lottie Animation – Motion Kit

Motion Kit output1024 × 1024 · 60 fps · 4 s loop

A Claude skill that animates an SVG illustration. From one prompt it returns a Lottie file, an animated SVG and a preview page, all built from the same timings so they match frame for frame.

  1. Design the illustration in Figma and export it as SVG.
  2. Open Claude Code, attach the SVG and paste the Motion Kit prompt.
  3. Claude splits the art into parts, plans a short loop and builds the files.
  4. Download Lottie (.json or .lottie), SVG or the preview page.

Editable Figma Illustrations with ChatGPT and Figma Agent

Video1:12 · with sound

ChatGPT handles the idea and the look and writes a design breakdown. The Figma agent draws from that breakdown as real, editable vector layers, so designers can change shapes and colours like any Figma file.

  1. Set up a style reference chat in ChatGPT.
  2. Ask for illustration directions as a 2 × 2 grid.
  3. Pick one and get a written design breakdown.
  4. Paste the breakdown, not the image, into the Figma agent.
  5. Keep one Figma chat so the set stays consistent, then generate in bulk.
